# 我的世界：迷你方块冒险

A tiny Minecraft-inspired terminal demo that renders a small block world with terrain, water, a tree, a player, and an inventory.

## Getting Started

```bash
node index.js
```

## Features

- Procedurally shaped block terrain
- Emoji blocks for grass, dirt, stone, water, wood, leaves, and the player
- Simple adventure prompt and inventory output
