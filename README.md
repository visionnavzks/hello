# Hello World

A simple hello world project.

## Getting Started

```bash
npm install
npm start
```

## Blender Scene

This repository includes `crocodile_bicycle_mountain_road.py`, a Blender Python script that procedurally builds an imaginative realistic scene: a crocodile riding a bicycle on a rich mountain road background.

Run it with Blender:

```bash
blender --background --python crocodile_bicycle_mountain_road.py
```

The script saves `crocodile_bicycle_mountain_road.blend` in the working directory.
